# mitu-back

# Предустановки

1. Установить Node.js
2. Установить npm
3. в .env файле изменить переменные на свое усмотрение (или оставить как есть)

# Запуск

В корне проекта запустить последовательно команды:
1. `cd todo-frontend && npm i && npm run dev` - запуск фронтенда.
2. Открыть новый терминал.
3. `cd todo-backend && npm i && node server.js` - запуск бэкенда.
4. Открыть в браузере `http://localhost:5173` (порт может отличаться, смотреть на выданный порт в консоли фронтенда)
